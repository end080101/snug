对外提到外部 PR 的贡献（小红书、README 致谢、Release 说明、issue 回复），按他实际做的份量写，不要写成整个功能是他做的。

**Why:** 11-24 主人纠正小红书文案：Nexmoe 的 PR #58 只是一个很浅的适配器，大头是我们通读 CrossDesk 源码、重写手势层、全面审查和真机实测后才合并的；写「感谢 Nexmoe 的 PR」配上功能介绍，读起来像功能全是他做的。

**How to apply:** 先讲清我们自己做了什么（源码核对、重写、实测），再谢贡献者具体做的那一块，如「初版 PR」「初版适配」。README 致谢已改为「Nexmoe（#58，CrossDesk 初版适配）」。相关：[[project-crossdesk]]、[[feedback-doc-writing]]
