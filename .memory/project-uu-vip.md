- **事实**（11-19 官方权益页）：免费版 1080p 30 帧；VIP（238 元/年）含多屏、无线副屏、虚拟屏、超级屏，2026-12-01 起生效
- **对外立场**（主人定，三版才定稿）：「若你恰为 UU远程 VIP 用户，欢迎一试」+ 独立社区项目、与 UU远程 无商业关联、不必为 Snug 专门开通；末句「目前专注 UU远程，暂不自行适配其他远控软件；对接部分已抽为可替换的适配层，欢迎提 PR 接入或 fork 自行适配」。README 三种语言、致谢、2.7.0 Release 页已按此改；应用内更新日志与 v2.7.0 标签说明仍是旧说法，主人没要求改
- **免费版行为不实测**（11-18 主人定）：不做免费账号实测，也不再提醒；对外不写，也不包装成绕开 VIP 的办法
- **专注 UU，暂不接其他远控**（11-19 主人定；11-23 对 CrossDesk 破例，PR #58 要合，见 [[project-crossdesk]]）：RustDesk 实测卡在第一步（公共服务器要求控制端登录、延迟 800ms 以上，局域网直连连不进，国内有墙）；ToDesk、向日葵的虚拟屏同样只在付费档（各 158 元/年起），换过去省不了钱。改为把对接 UU 的部分抽成适配层给社区留口子（主人：「就算咱们不做，也要留个口子给别人做」），见 [[project-remote-adapter]]。RustDesk 源码结论在 docs/remote-adapter 的调研里。#47 推荐 StarDesk（UU远程 国际版，暂免费）同样婉拒并关闭（11-21）：主人只用 UU，不用的不测、不负责，适配层已留口子。系统设置的录屏/辅助功能列表可能残留一项 RustDesk

**Why:** UU 收费改变了 Snug 的用户前提，措辞稍有偏差就像替 UU 推广。
**How to apply:** 提到 UU 收费一律照上面的立场写；要不要自己接其他远控，主人点头再议。
